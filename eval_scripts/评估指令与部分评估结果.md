# HumanEval / MBPP 评估说明

## 评估方法

在仓库根目录执行（`run_code_eval.sh` 会按脚本位置解析 `REPO_ROOT`，不依赖当前工作目录）：

```bash
bash eval_scripts/run_code_eval.sh <recipe> [MODEL]
```

- **`<recipe>`**：与 `eval_scripts/dream_*.sh`、`dream-coder.sh`、`llada_*.sh` 中命令一一对应的函数名。列出全部名称：

  ```bash
  bash eval_scripts/run_code_eval.sh list
  ```

- **`[MODEL]`**（可选）：覆盖该条 recipe 里的 Hugging Face id 或本地 checkpoint 路径（对应各函数中的 `pretrained=` / `model_path=` / `CKPT_DIR` / `--model`）。

命名习惯（节选，完整以 `list` 为准）：

| 前缀 | 含义 |
|------|------|
| `dream_humaneval__*` / `dream_mbpp__*` | `lm_eval` + `utils/utils_Dream/eval_instruct`，任务多为 `humaneval_instruct`、`mbpp_instruct` |
| `dream_coder__*` | EvalPlus，`utils/utils_DreamCoder/code_eval`；`PYTHONPATH` 固定为仓库内 vendored `utils/utils_DreamCoder/code_eval/evalplus`；Python 3.11+ 用 `python -P -m evalplus.evaluate`，否则在 `REPO_ROOT` 下执行以避免与仓库根外层 `evalplus` 包冲突 |
| `llada_*__*` | `utils/utils_LLaDA` 下 `eval_llada.py` 等 |

示例：

```bash
# Dream 系 HumanEval（entropy / multi-block 等见 recipe 名）
bash eval_scripts/run_code_eval.sh dream_humaneval__d3llm_entropy
bash eval_scripts/run_code_eval.sh dream_humaneval__d3llm_multiblock_t01 /path/to/local/d3LLM_Dream

# Dream Coder（EvalPlus + dllm；第二参数换成本地合并权重等）
export HF_ALLOW_CODE_EVAL=1   # 若环境需要，可按官方 EvalPlus 要求设置
bash eval_scripts/run_code_eval.sh dream_coder__humaneval_d3llm_multiblock
bash eval_scripts/run_code_eval.sh dream_coder__humaneval_d3llm_multiblock output_model/merged_d3LLM_DREAM_Coder

# LLaDA 系 HumanEval（部分 recipe 末尾会调用 postprocess）
bash eval_scripts/run_code_eval.sh llada_humaneval__d3llm_entropy_multiblock
```

调试 EvalPlus 导入或路径时：`EVALPLUS_DEBUG=1 bash eval_scripts/run_code_eval.sh dream_coder__humaneval_vanilla_dllm`。

结果与日志：

- **Dream 系（lm_eval）**：在 `utils/utils_Dream/eval_instruct` 下运行，输出目录由各 recipe 的 `--output_path` 决定（常见为 `./eval_tmp/multi_block_cot` 等），内含 `results_*.json`、`samples_*_instruct_*.jsonl`（具体文件名随任务名变化）。
- **Dream Coder（EvalPlus）**：在 `utils/utils_DreamCoder/code_eval` 下运行，默认产出位置以 EvalPlus 为准（亦可将结果保存到自建的 `evalplus_results/` 等目录，视调用方式而定）。
- **LLaDA 系**：在 `utils/utils_LLaDA` 下运行，输出多在 `evals_results/d3llm/<任务>-.../<模型路径编码>/`，**HumanEval** 为 `samples_humaneval_*.jsonl`，**MBPP** 为 `samples_mbpp_*.jsonl`；部分 recipe 会对最新 `samples_*.jsonl` 自动执行 `postprocess_code_humaneval.py` / `postprocess_code_mbpp.py`。LLaDA 系 HumanEval 的 pass@1 以 postprocess 打印为准（lm_eval 表格中 pass@1 为 0 属预期）。
